Bienvenido al sistema SISFIS

Plataforma académica para registrar, consultar, actualizar y eliminar informes de fiscalización mediante servicios API RESTful. El informe se genera con el formato oficial de Informe de Supervisión y se actualiza automáticamente mientras se llena el formulario.

Importante: Todos los datos utilizados en esta práctica son ficticios y tienen fines exclusivamente educativos.
